

## 整数在计算机中的表示

### 无符号数

- 所有二进制位都用来表示数值大小，没有符号位。
- $n$ 位无符号数的表示范围：$0 \sim 2^{n} - 1$
- 例如 8 位无符号数：`00000000`（0） ∼ `11111111`（255）

### 有符号数

计算机中普遍使用**补码**表示有符号整数。

#### 原码、反码、补码

- **正数**：原码 = 反码 = 补码，符号位为 `0`。
- **负数**：
  - 原码：符号位为 `1`，数值部分同其绝对值。
  - 反码：符号位不变，其余位对原码数值位按位取反。
  - 补码：在反码的最低位加 $1$。

> 常用求负数补码的方法：  
> 1. 其绝对值的二进制 → 按位取反 → 加 $1$  
> 2. 其绝对值的二进制 → 减 $1$ → 按位取反（等价于笔记中 `先-1，再取反`）  

**示例（8位）**  
$-6$ 的补码：  
- 正数 6：`00000110`
- 取反：`11111001`
- 加 1：`11111010`  ← 即 $-6$

另一种方法：  
`00000110` → `00000101`（减1） → `11111010`（取反）

$$(-6)_{10} \rightarrow (11111010)_2 (\text{补码})$$

> 符号位 `1` 表示负数。

#### 补码转十进制负数

1. 先对该补码按位取反。
2. 再加 $1$。
3. 将得到的二进制数当作无符号数看待，其值就是该负数的绝对值。

**示例**：补码 `1010`（4位）
- 取反：`0101`
- 加 1：`0110` → 当作无符号数为 $6$  
所以 `1010` 表示 $-6$。

#### 相反数的求法

> **一个数的相反数 = 对该数的补码取反加一**（对自身也适用，包括负数）

- 例如 $6$ 的补码 `0110` → 取反加一 → `1010`（即 $-6$）
- 再对 `1010` 取反加一 → `0110`（又变回 $6$）

**坑：最小的那个负数取相反数会溢出！**

- 以 8 位补码为例，范围是 $-128$ ~ $127$。
- $-128$ 的补码是 `10000000`，取反加一后依然是 `10000000`，得不到 $+128$（因为 $+128$ 在 8 位补码中无法表示）。
- 数学表达：对于 $n$ 位补码，最小负数为 $-2^{n-1}$，其相反数 $2^{n-1}$ 超过了补码正数表示范围，会溢出。

## 位运算

位运算直接对二进制位进行操作，**左右操作数都会被完整求值**。

| 运算符   | 名称         | 规则                                      |                      |
| ----- | ---------- | --------------------------------------- | -------------------- |
| `&`   | 按位与        | 两位同时为 `1`，结果才为 `1`                      |                      |
| `\|`   | 按位或                                     | 两位中有一个为 `1`，结果即为 `1` |
| `^`   | 按位异或       | 两位不同时结果为 `1`，相同时为 `0`                   |                      |
| `~`   | 按位取反       | 单目运算符，`0` 变 `1`，`1` 变 `0`（注意符号位也会变）     |                      |
| `<<`  | 左移         | 各二进制位全部左移若干位，高位丢弃，低位补 `0`（相当于乘以 $2^k$）  |                      |
| `>>`  | 算术右移       | 各二进制位右移，**高位补原来的符号位**（相当于除以 $2^k$ 向下取整） |                      |
| `>>>` | 逻辑右移(Java) | 右移后高位始终补 `0`（无符号右移，C/C++根据类型区分）         |                      |

### 位运算与逻辑运算的区别

- **位运算**（`&`, `|`, `^`, `~`）：操作对象是整数的每个二进制位，**左右表达式都会执行**。
- **逻辑运算**（`&&`, `||`）：操作对象是布尔值，且具有**短路特性**（从左到右“穿透执行”），一旦结果确定就不再执行后续表达式。
  - `a && b`：若 `a` 为 `false`，则不再计算 `b`。
  - `a || b`：若 `a` 为 `true`，则不再计算 `b`。

## 常用位运算技巧

在算法中，位运算常可以大幅提高效率。

### 判断奇偶
```java
if ((x & 1) == 0) { /* 偶数 */ }
else { /* 奇数 */ }
```

### 乘/除 $2$ 的幂
- `x << n` 相当于 $x \times 2^n$
- `x >> n` 相当于 $x / 2^n$（向下取整，算术右移）

### 交换两个数（不用临时变量）
```java
a ^= b;
b ^= a;  // b 变成原来的 a
a ^= b;  // a 变成原来的 b
```

### 判断一个数是否是 2 的幂
```java
x > 0 && (x & (x - 1)) == 0;
```
- 原理：2 的幂的二进制中只有一个 `1`，减 1 后原来 `1` 的位置变为 `0`，更低位的 `0` 变为 `1`，按位与后一定为 `0`。

### 获取二进制中最右侧的 1
- `x & -x` （`-x` 是 `x` 的补码，取反加一）
- 例如 $12$（`1100`），最右侧的 1 在第二位，`12 & -12` = `0100` = 4。

### 将最右侧的 1 变为 0
- `x & (x - 1)`
- 常用于统计二进制中 1 的个数（每次循环消去一个 1）。

### 统计 1 的个数（Brian Kernighan 算法）
```java
int count = 0;
while (x != 0) {
    x = x & (x - 1);
    count++;
}
```

### 将最低位的 0 变为 1
- `x | (x + 1)`

以上技巧在算法竞赛、底层优化、位掩码等场景中非常实用。
