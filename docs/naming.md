# 资料命名规范

## 目录结构

每门课使用固定的资料类型目录。没有对应资料时不要新建空目录，不要为了凑目录上传生成内容。

```text
课程名/
  复习讲义/
  往年真题/
  课件PPT/
  课件资料/
  课件资料包/
  题库练习/
  答案解析/
  笔记总结/
  待复核课件PPT/
  待复核资料/
```

## 资料类型目录

- `复习讲义`：考前复习讲义、知识点讲义、课程知识框架。
- `往年真题`：往年真题、回忆版真题。
- `课件PPT`：真实 `.ppt` 或 `.pptx` 课程课件。
- `课件资料`：PDF 课件、DOCX 讲义、从课件包拆出的单文件资料。
- `课件资料包`：无法安全拆分但来源明确的 ZIP 压缩包。
- `题库练习`：习题集、题库、练习题。
- `答案解析`：答案、解析、题解。
- `笔记总结`：同学整理的公开笔记、总结、索引。
- `待复核课件PPT`：疑似真实课件但来源、课程或版本暂未确认的 PPT/PPTX。
- `待复核资料`：有复习价值但来源、年份、课程归属或公开边界需要复核的资料。

不要创建 `完整复习包`、`付费资料`、`会员资料` 等公开仓库不应出现的目录。

## 文件命名格式

统一使用：

```text
课程名_资料类型_关键信息[_年份或版本].扩展名
```

示例：

```text
离散数学_真题_软件学院23级.pdf
大学物理_课件_2023高斯定理.pdf
面向对象程序设计Java_课件_第1章Java概述.pptx
Web编程基础_考前复习知识点讲义.pdf
高等数学A（二）_课件_D10-3三重积分_02.ppt
```

## 资料类型词

- `真题`：往年真题、回忆版真题。
- `样卷`：模拟卷、样题、练习卷。
- `课件`：真实课程 PPT/PPTX/PDF 课件。
- `讲义`：复习讲义、知识点讲义。
- `题库`：习题集、题库、练习题。
- `答案解析`：答案、解析、题解。
- `笔记`：同学公开整理的笔记、总结、知识点索引。
- `资料包`：无法拆分但来源明确的 ZIP 压缩包。

## 字符规则

- 使用中文课程名，不使用拼音缩写。
- 多编号使用顿号：`D7-1、2、3`。
- 高数章节编号统一使用 `D` 前缀：`D7-5`、`D8-1`、`D10-3`，不要混用 `7-5` 或 `8-1`。
- 版本说明使用下划线：`_精简版`、`_删减版`、`_02`。
- 避免使用英文逗号、斜杠、冒号、问号、星号、引号、尖括号和反斜杠。
- 文件名不要出现 `副本`、`final_final`、`新建文件`、`未命名`。

## 真实性要求

- `课件PPT` 目录只放真实 `.ppt` 或 `.pptx` 课件。
- PDF 课件放入 `课件资料`。
- 能安全拆分的课件压缩包，优先拆分后放入 `课件资料` 或 `课件PPT`。
- 不能安全拆分但来源明确的压缩包，放入 `课件资料包`。
- 来源不确定、课程归属不确定或年份不确定的资料，先放入 `待复核...` 目录并在 PR 中说明。
- 禁止上传 AI 生成 PPT 冒充课程课件。

## Manifest 同步

所有新增、删除、移动、重命名资料，都必须同步更新 `manifest.json`。至少保留：

- `subject`
- `role`
- `title`
- `publicPath`
- `bytes`
- `sha256`

建议逐步补充来源字段：

- `year`
- `college`
- `major`
- `sourceType`
- `sourceNote`
- `reviewStatus`
- `containsPersonalInfo`
- `licenseStatus`

提交前运行：

```bash
node scripts/validate-materials.mjs
```
